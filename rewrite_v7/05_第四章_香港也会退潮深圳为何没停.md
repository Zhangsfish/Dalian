# 四、香港也会退潮，为什么深圳没有停下来

深圳最初也不是从零创造了一套完整工业体系。

它同样是一个搭车者。

改革开放初期，香港工资和土地成本不断上升，大量玩具、服装、电子装配和轻工业生产环节开始越过深圳河。

香港提供资本、订单、客户和市场连接。

深圳提供土地、劳动力和越来越成熟的生产能力。

从这个意义上说，日本之于大连，与香港之于深圳非常相似。

两座城市第一轮增长，都来自一个更成熟经济体向外转移产业。

而这种外部发动机都不可能永远高速运转。

香港制造业该搬的总会逐渐搬完，日本企业的海外布局也会从扩张期走向成熟期。

所以真正决定后来命运的，不是第一辆车会不会减速。

而是：

> **第一辆车减速之前，本地有没有长出自己的发动机。**

深圳后来发生的关键变化，首先出现在产业组织里。

电子和通信产业越来越可以被拆成专业环节。

模具有人做，PCB有人做，结构件有人做，电机、电源、组装、软件也逐渐有各自独立的公司。

供应商不一定只绑定一家主机厂。

它们可以同时服务不同客户。

于是，一个新公司想做产品，不必先拥有一家完整的大企业。

它可以在附近找到设计、打样、模具、零件、小批量生产和组装能力。

创业开始变得更像重新组合，而不是从零建造整套体系。

与此同时，工程师也在流动。

企业倒闭了，人还在深圳。

一个项目失败了，团队成员可以进入下一家公司。

供应商失去一个客户，还可以去寻找另一个客户。

于是企业会死，但能力并不一定随着企业一起消失。

这已经与传统大型组织有很大不同。

但如果只有供应链，没有市场，这一切仍然可能停留在代工层面。

深圳真正幸运的第二件事，是中国本土市场恰好在同一时期迅速变厚。

1990年代以后，通信网络扩张，电话和电子产品进入越来越多家庭，企业信息化开始普及，中国出现了大量第一次发生的需求。

这些需求并没有被跨国公司完全覆盖。

于是深圳企业第一次获得了一个重要机会：

不再只等香港和外国客户告诉自己做什么，而是自己去寻找中国客户的问题。

华为早期的成长就是一个典型例子。

它最初销售别人的交换机，后来开始自己研发，并从跨国公司覆盖相对薄弱的县城、农村和本土通信市场切入。

这一步的意义不只是“开始做自己的产品”。

它意味着本地企业开始拥有客户。

只要直接面对客户，企业学到的东西就会改变。

以前主要学的是：

怎么生产，怎么交付，怎么满足甲方要求。

现在还要学习：

客户为什么付钱，哪些功能真正重要，什么价格能卖出去，下一代产品应该怎么定义。

生产知识开始变成产品知识。

而一旦本地企业成长为新的甲方，又会反过来产生新的本地订单。

华为需要设备和零部件。

比亚迪需要材料、模具和电子系统。

大疆需要电机、传感器、结构件和软件人才。

这些公司不只是利用深圳的供应链。

它们也在持续给供应链制造新的需求。

于是，一个新的循环形成了：

> 香港订单  
> → 本地生产能力  
> → 专业供应商  
> → 新企业可以低成本调用这些能力  
> → 中国市场提供第一批客户  
> → 本土企业成长为新的甲方  
> → 再养出更多供应商、工程师和创业者。

这时，深圳与香港的关系开始发生变化。

早期，是香港企业组织深圳的土地、劳动力和工厂。

后来，越来越多深圳企业开始自己组织深圳的资源。

这就是从“搭车”到“造车”的区别。

“搭车”是进入别人已经组织好的产业体系。

路线、产品、客户大体都已经存在，后发者最重要的是学习和执行。

“造车”则是把第一轮学习变成自己的企业、自己的客户和自己的产业组织能力。

再往前一步，才是“铺轨”。

当本地企业逐渐接近技术前沿，前面已经没有成熟答案可以复制时，它必须自己寻找新技术、新产品甚至新的市场。

这时增长越来越依赖竞争、试错和失败后的重新组合。

深圳并不是在某一天突然从代工城市变成创新城市。

它只是逐渐完成了三步之间最重要的一次切换：

> **从依靠别人制造需求，转向本地企业自己制造需求。**

大连第一轮也成功搭上了车。

真正没有同等程度完成的，是下一步。

但如果把这个差异全部归结为“模块化供应链”，同样会走得太远。

因为模块化并不是历史的终点。
