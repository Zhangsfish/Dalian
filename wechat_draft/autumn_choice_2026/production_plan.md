## 1. 编辑判断

核心矛盾不是「不够坚定」，而是价值不可公度、可能的自我具有多样性、取舍具有不可逆机会成本、偏好会在比较中建构、未知的自我可能被经历改变，以及真实的经济约束。插图只负责让读者体会这些摩擦，不抢走论证。目标是文学纪实摄影与严肃中文杂志的视觉气质，**不是** PPT、海报、情绪短视频、鸡汤长图。

色彩：低饱和灰蓝 / 微暖钨丝灯 / 真实肤色；克制颗粒，现实质感。统一无文字、无品牌标识、无假造录用通知公司名称、无校徽。人物只呈现普通中国应届生的生活场景，不把人物塑造成商业精英。

## 2. 图像清单与精确插入位置

### COVER：`cover_autumn_choice.jpg`

- 类型：公众号封面专用；横向 2.35:1 目标裁切；高分辨率，重要主体处于中心安全区；**图中不直接生成汉字**，平台标题字段另填。
- 画面：秋末夜晚的中国大学宿舍/出租屋，从人物背后看一位应届毕业生坐在窄桌前，桌上是电脑、三四张无可读文字的纸、咖啡杯和泛黄的便利贴。窗外是普通中国城市散乱而柔和的夜灯，不是豪华 CBD。人物静止，不沮丧也不振奋。可留左侧暗部空间，形成编辑式安静张力。
- 对应矛盾：想过未来却仍需在今晚作出决定。
- 反例：分叉道路、三个巨型企业图标、金币天平、励志标语、哭泣人物、可辨认公司 Logo。

### FIG-01：`01_three_possible_lives.jpg`

- **放置锚点**：紧接原文「更奇怪的是，这些想法并不像简单的见异思迁。你真的欣赏创造，也真的珍惜自由；你渴望有所成就，同时又觉得平静地度过一生没什么不好。」这一自然段之后。
- 视觉：招聘会结束后的大学公共走廊；一位青年手拿没有可读文字的资料、独自站在普通建筑内，远处的人群散去；一侧玻璃映出明亮现代办公室般的光，另一侧走廊尽头是下午阳光和校园树影，形成若隐若现的两种气息，但仍是一张写实照片，没有人为分割的三联画。
- 传达：每一种想象都真诚，不暗示正确选项。
- 比例：横向 3:2 或 16:9；手机端留出可读物体轮廓。
- 图注：「秋招让几种值得过的人生，在同一个人身上同时变得具体。」（编辑性图注；明确为 AI 生成概念配图）

### FIG-02：`02_opportunity_cost.jpg`

- **放置锚点**：紧接原文「但签下三方协议之后，时间就开始具有排他性。你在深圳度过的三年，不可能同时在大连度过；你花在工作上的那些夜晚，也不能再拿去经历另一种生活。」这一段之后。
- 视觉：接近夜晚的普通火车站候车大厅，一位二十多岁中国毕业生背对镜头坐在长椅上，脚边简单行李箱，前方列车信息屏仅为无法辨认的光块，两侧不同方向的人流轻微运动模糊。安静、普通、并不悲惨。
- 传达：不是选择胜利者，而是时间的排他性；不要做分叉路对比。
- 图注：「有些代价不是失去一份工作，而是无法同时拥有另一种生活。」（AI 生成概念配图）

### FIG-03：`03_family_and_choice.jpg`

- **放置锚点**：紧接原文「对于需要承担家庭经济责任的学生，失业风险不是一个抽象概率。对家境宽裕的人来说，试错或许只是几个月没有收入；对另一些人来说，一次失败可能意味着父母继续承担生活费，甚至影响整个家庭的安排。」这一段之后。
- 视觉：中国普通家庭住宅傍晚，厨房或餐桌一角；旧一点但整洁的桌面有一本笔记本、手机呈现来电光但无任何文字，一双成年父母的手在一旁整理碗筷，青年人的手放在桌上，未见面孔；暖色日常灯光，真实、有生活气息，拒绝刻意煽情。
- 传达：经济约束不是抽象模型，而是桌上的生活。
- 图注：「同一份录用通知，在不同家庭里意味着不同的风险。」（AI 生成概念配图）

## 3. 版式映射

- 封面图片放在公众号「封面」独立字段；正文开始**不重复使用封面**（避免占用读者第一屏）；使用开头一至两自然段作浅灰 lead 框。
- 不虚构作者名，未确认就不填。
- 本文无原始小标题；可通过自然段的留白和插图形成节奏，**不擅自增加观点性章节标题**。
- 保留原稿的三句关键论断，以轻量独立重点句形式处理，避免使用彩色强调：①「或许问题并不在于……」②「秋招最残酷的地方之一……」③结尾提问。
- 引文、理论名词不要伪造学术脚注；稿末参考资料需补可核查的来源 URL 后按 Skill 的滚动资料区处理。如无确认的来源链接则不写虚构参考文献。
- 每张正文图最大宽 100%，无阴影、无卡片、无强行圆角；右对齐浅灰 12px 图注，标明「AI 生成示意图」；绝不标示为真实新闻纪实照。
- 正文 16px / 1.86 行高 / 20–26px 段距，适度合并短段，不能改变句子。
- 复制区域完全 inline，不能依赖 CSS class / script；button 写 Clipboard 的 text/html + text/plain。
- 图片全部 HTTPS；预览图片检查必须通过，粘贴后如不能转存，需手动逐张上传修复。

## 4. 生成与验收流程

1. 从本篇原文保存 `article_source.md`，正文逐字核对，无私改。
2. **先审阅本规格，再逐张文生图**：依次 COVER → FIG-01 → FIG-02 → FIG-03。需检查 AI 生图是否出现扭曲手指、伪造文字/标识、视觉套路化。
3. 统一输出 JPG（建议正文宽 ≥ 1400px，封面目标 2.35:1，尽量 ≥ 900×383），体积控制在公众号常用限制内，不以牺牲画面质量为代价。
4. 把图片保存到 `wechat_draft/autumn_choice_2026/assets/`，在 `article_source.md` 的锚点插入相对图片路径与图注。
5. 使用仓库 `skills/wechat-editorial-copy/scripts/render.py` 运行：
   `python render.py --input wechat_draft/autumn_choice_2026/article_source.md --output wechat_draft/autumn_choice_2026/article_wechat_preview.html --asset-base https://raw.githubusercontent.com/Zhangsfish/Dalian/editorial/autumn-choice-20261009/wechat_draft/autumn_choice_2026/assets`
6. 核对输出 HTML 复制区仅简单标签和 inline style；HTTP 图地址 200；前后原文字句完整；按钮可用；截图审阅桌面/手机长图。
7. 打开本地预览 HTML，复制正文到微信公众号编辑器，保存预览并用真机微信查看图注、图片转存与引文降级行为。
8. 用户确认后才发布。**本轮目标仅为 PRE-PUBLISH，不自动对外发布**。
