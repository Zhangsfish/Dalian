# 大连

这组稿件围绕一个问题展开：

> **为什么一个曾经成功承接全球产业转移、拥有港口、工业基础、日韩资本、人才和强政府执行力的明星城市，没有像深圳一样，把外来的增长发动机变成自己的发动机？**

## 当前终稿

- [V8｜《大连为何失落：一座城市如何错过下一轮时代》](./大连为何失落_终稿_v8.md)

V8 为当前主稿。主结构仍是三条轴：
- **时间轴**：技术范式变化改变组织能力的相对价值；
- **组织轴**：第一轮成功形成深度能力，也提高后续重组成本；
- **地理轴**：大连是优秀门户，但辽中南没有充分形成珠三角式高密度区域网络。

在 V7 基础上，V8 增加了一个经过专项研究审计的短侧栏 **「如果真的是薄熙来呢？」**。结论不是否认政治网络，而是把它收窄为一个可能的边际放大机制；公开数据不支持把2012后的政治变化写成大连长期失落的主因。

## 核心判断

大连的失落，不是因为没有承接产业，也不是因为没有学习技术。真正的问题是，第一轮外来增长形成的能力，没有充分转化为可被本地企业自由重组、并直接连接市场的公共能力池。

东北腹地衰退、日本市场成熟、老工业城市的组织遗产和空间网络结构，随后把这个缺陷放大了。
