## 核心判断

大连的失落，不是因为没有承接产业，也不是因为没有学习技术。真正的问题是，第一轮外来增长形成的能力，没有充分转化为可被本地企业自由重组、并直接连接市场的公共能力池。

东北腹地衰退、日本市场成熟、老工业城市的组织遗产和空间网络结构，随后把这个缺陷放大了。
