# research/bo2012

## 研究问题

2012年薄熙来政治失势之后，大连的相对失速有多少属于：

- 辽宁/东北共同下行；
- 大连自身产业、地产、对日与信用结构；
- 政治网络和地方治理变化。

本目录只研究可验证的经济机制，不评价政治人物个人。

## 当前状态

**S05 已完成。**

主结论：

> 2014—2015大连相对省外参照城市确有明显失速，但大部分与辽宁共同的地产、投资和区域下行重叠。政治网络因素仍可能通过边际融资、项目协调和民间预期发挥放大作用，但公开数据不支持“2012后财政、国家项目、干部和融资全面断流”的强版本。

工作叙事权重（不是因果估计）：

- 辽宁/东北共同下行 + 地产/高投资模式：约65%，参考范围55%—75%
- 大连特有结构暴露：约25%，参考范围15%—35%
- 2012政治网络/治理冲击：约10%，参考范围0%—15%

不要把这组数字写成“统计证明”。

## 停止规则

除非新增以下高识别价值数据，否则暂停继续扩展：

- 大连/供体城市可比的央企新增投资流
- 企业/银行微观信贷
- 可核验政治网络名单与项目匹配
- 同一vintage的更长城市产出面板

继续堆新闻案例不会显著提升因果识别。
