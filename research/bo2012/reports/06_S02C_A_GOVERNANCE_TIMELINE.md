# S02C-A｜干部与治理传导：2012后没有“一把手立即洗牌”，但2014—2016出现另一层治理压力

日期：2026-10-07  
状态：**治理机制第一轮完成；结论仍为机制约束，不是政治效应估计。**

这一轮只回答一个窄问题：

> 如果“薄熙来2012年倒台→大连地方治理迅速失效”成立，公开数据里首先应该看到什么？

优先检查四类可观察结果：

1. 党政一把手是否在2012附近异常频繁更替；
2. 市场主体进入是否迅速塌缩；
3. 民间投资是否持续、单调下滑；
4. 重大项目是否出现明显停摆。

结论先写：

> **2012后大连确实在2014—2015发生经济失速，但“2012后立刻换了一批领导、行政机器马上失灵”这个最简单的治理版本，现有事实不支持。**

更可研究的版本是：

> **政治网络断裂没有立即更换大连一把手，但可能通过干部激励、项目选择、政商预期和后续政治生态变化滞后传导。**

## 1. 2012是政治事件点，但不是大连党政一把手更替点

新增：

`data/leadership_timeline.csv`

最关键的时间线：

### 市委书记

- 夏德仁：2009.05—2011.06
- 唐军：**2011.06—2017.02**
- 谭作钧：2017.02起，研究窗口内继续任职

唐军的公开简历显示，他2011年6月进入大连任市委书记，直到2017年2月才离开，随后转任国家工商总局党组成员、副局长。

因此：

> **2012年薄熙来政治事件发生时，大连市委书记没有被同步撤换；唐军继续在任约5年。**

### 市长

- 夏德仁：2003.01—2009.05
- 李万才：2009.05代理，2010.01正式任市长，**至2014.12.29**
- 肖盛峰：2014.12.29代市长，2015.01当选，至2018.01
- 谭成旭：2018.01—2019.10，后转任鞍钢集团董事长、党委书记

李万才在2012事件后仍继续担任市长约两年九个月；2013年还在新一届人大再次当选。

### 直接含义

`outputs/top_leadership_changes.csv`显示：

| 年份 | 市委书记更换 | 市长更换 |
|---|---:|---:|
| 2011 | 1 | 0 |
| **2012** | **0** | **0** |
| **2013** | **0** | **0** |
| 2014 | 0 | 1 |
| 2015 | 0 | 0 |
| 2016 | 0 | 0 |
| 2017 | 1 | 0 |
| 2018 | 0 | 1 |

所以：

> **“薄倒台→2012/2013马上换了一批大连最高层干部→经济立即掉速”并不符合公开任职时间线。**

这不否定政治网络假说。

它只是把H2从“干部更替冲击”收窄成：

- 同一批地方领导失去外部政治连接后，资源协调能力是否改变；
- 同一批领导的风险偏好/项目行为是否改变；
- 更低层级干部与政商网络是否被调整；
- 2014—2016是否出现滞后的政治生态变化。

## 2. 市场主体登记没有在2012后出现“行政冻结”

新增：

`data/governance_indicators.csv`

公开统计公报里的新注册企业数：

| 年份 | 新注册各类企业 |
|---|---:|
| 2007 | 12,363 |
| 2010 | 17,065 |
| 2013 | 16,072 |
| 2014 | 27,310 |
| 2015 | 29,942 |
| 2016 | 32,313 |
| 2017 | 38,728 |

从表面看，2013以后不是下降，而是迅速增加。

这意味着至少不能说：

> “2012后大连企业注册和市场准入马上停摆。”

但这组数据**不能反过来证明营商环境变好**。

原因非常明确：

2014年国务院推进注册资本登记制度改革，2014年3月1日起注册资本认缴等新规则实施，市场主体准入门槛全国性下降。

因此2014年大连新注册企业同比+69.9%的跳升，至少一部分是全国制度改革造成的结构断点。

所以本项目只把企业注册数用作：

> **排除“市场主体登记立即冻结”的强版本。**

不把它当作地方治理质量指数，也不拿2014后的增长率做政治效应。

## 3. 民间投资没有形成一条“2012后一路坠落”的干净曲线

目前能核验的大连民间投资增速：

- 2014：**+2.4%**
- 2017：**+22.4%**
- 2018：**+17.1%**
- 2019：**−9.3%**

2015—2016的大连市级同口径民间投资增速本轮尚未找到，保留缺口。

现有数据只能说明：

> **民间投资并非2012后永久、单调下行。**

2014增长很弱，与当年整体投资只增长4.6%、房地产开发投资下降16.4%一致；2015全社会固定投资又下降32.7%。

但到2017、2018，民间投资重新出现明显正增长；2019再转负。

因此，如果H2“地方治理能力恶化”要通过民间投资来识别，至少需要：

- 补齐2011—2016同口径序列；
- 同时与武汉/青岛等控制城市比较；
- 控制全国和辽宁共同投资周期；
- 区分房地产、制造业与一般民间投资。

现阶段不能从几个孤立年份给治理能力打分。

## 4. “重大项目在2012后全面停摆”也不符合公开记录

几组可核验项目事实：

### 2013

大连政府工作报告回顾2013：

- 实施亿元以上重大项目 **1028项**
- 总投资1.58万亿元
- 完成亿元以上重大建设项目投资 **3800亿元**

### 2015

在经济增速已经降至4.2%、固定资产投资下降32.7%的年份，政府工作报告仍列出一批实际推进或获得批复的重大事项：

- 中国（大连）跨境电子商务综合试验区获国务院批准
- 中日韩（大连）循环经济示范基地获国务院批准
- 普兰店撤市设区获批
- 恒力石化炼化一体化项目开工
- 英特尔55亿美元存储器项目落地
- 新机场规划方案通过国家有关部门初审
- 丹大快铁、地铁1/2号线等项目推进/投运

这些材料不能证明政治网络毫无损失，因为许多项目可能有多年筹备和存量惯性。

但它们足以排除：

> “2012后国家项目、央企/外资重大项目全面停止”的绝对版本。

### 2016—2017

2016：
- 开复工亿元以上重大项目 **660个**
- 完成投资 **1176.4亿元**

2017：
- 开复工亿元以上项目 **621个**
- Intel项目当年投资178亿元
- 恒力项目当年投资200亿元

因此，真正值得问的不是：

> 有没有项目？

而是：

> **新项目流、项目质量、项目来源、审批周期和民间投资的相对表现是否变差？**

这正是下一步项目账本要做的。

## 5. 一个治理扰动确实在后期出现：2016年常务副市长曹爱华被调查

2016年9月，大连市委常委、常务副市长曹爱华因涉嫌严重违纪接受调查。

公开简历显示：

- 2010.08—2012.12：大连市委常委、副市长
- 2013.01起：市委常委、常务副市长
- 2016.09接受调查

这说明2016年大连高层政府班子确实出现了重要纪律冲击。

但有两个边界：

1. 时间在2016年，晚于2014—2015最明显的相对增长偏离；
2. 单个副市长案件不能外推成“整个大连班子都失效”。

所以它更像：

> **辽宁政治生态和治理扰动在后期加深的一个可观察节点。**

而不是2012事件的直接中介证据。

## 6. 对“后来领导都不行”这个假说，怎样改成可检验命题

公开资料不能也不应该给领导个人做主观“能力评分”。

当前可以检验的命题分成三层：

### H2a：一把手稳定性下降

**目前不支持。**

2012—2014党政一把手高度连续；唐军一直任到2017。

### H2b：行政系统项目执行/市场服务能力下降

**仍开放。**

现有项目数量和企业注册不能证明明显停摆；但需要比较：
- 项目按期完工率
- 审批周期
- 民间投资
- 企业净进入而非只看注册
- 破产/注销
- 土地成交与项目实际开工

### H2c：政治网络损失改变同一批领导的资源和激励

**仍是最值得研究的治理版本。**

因为它不要求2012马上换人。

可能的链条是：

> 外部政治连接变化  
> → 同一批地方领导的可调用资源/政治预期发生变化  
> → 项目、信贷、招商和行政风险偏好改变  
> → 2014—2015逐渐体现在投资和增长上。

这条链与现有时间线不冲突，但尚缺直接证据。

## 7. S02C-A对四个假说的更新

### H1 政治网络断裂

**继续保留。**

领导没有马上换，反而使“关系/资源改变而非人事立即更换”成为更清楚的机制问题。

### H2 地方治理变化

**最简单的“一把手频繁更换”版本明显削弱。**

但“同一批领导失去资源与激励后行为变化”仍开放。

### H3 辽宁/东北共同冲击

仍然很强。尤其2015—2016投资和财政异常不能脱离辽宁整体环境解释。

### H4 结构暴露

仍然很强。2014—2015房地产、工业和投资均承压，需要与政治机制竞争。

## 8. 当前最公允的中间判断

经过S01—S02C-A，现在可以排除几个过强叙事：

### 不支持

> 薄熙来倒台后，大连2012立即换了一批领导，所以马上失速。

> 2012后中央和省级预算支持完全切断。

> 2012后企业注册、重大项目和民间资本活动全部停摆。

### 仍值得认真检验

> 2012政治网络断裂降低了大连的相对资源获取/协调能力，并通过同一批地方领导的项目、招商、信贷与风险偏好滞后传导，在2014—2015形成额外减速。

这是目前最符合时间线、也最可被数据证伪的政治机制版本。

## 9. 下一轮 S02C-B：做“重大项目/央企/中央资源流账本”

不再继续泛泛搜治理材料。

下一轮只抓最有识别价值的直接资源：

1. 2007—2019重大央企/中央项目
2. 项目申报/批复/开工/投产时间
3. 总投资与当年实际投资（能找到才记）
4. 发改委/国务院/央企来源
5. 是否事件前已启动
6. 2012后新增项目流是否下降
7. 与武汉/青岛做粗对照

核心要避免的错误：

> 2015在建一个740亿元项目 ≠ 2015获得740亿元政治资源。

必须把“存量项目规模”和“当年新增资源流”分开。
