# China Report 投稿要求冻结版

最后核对日期：2026-10-08  
目标期刊：**China Report**（SAGE / Institute of Chinese Studies, New Delhi）

> 本文件只记录官方要求与本项目内部执行口径。正式投稿前再做一次官网复核。

## 1. 官方硬性要求

### 1.1 期刊定位与文章类型
- China Report 是社会科学与国际关系领域的同行评议期刊，核心目标是增进对中国及其邻国的理解。
- 可投稿类型包括：
  - Research Articles
  - Perspectives and Commentaries
  - Book Reviews
- 本项目选择：**Research Article**。

### 1.2 费用
- 官方明确：**投稿和普通发表均不收取费用**。
- 可选 Sage Choice Open Access 需要付费；本项目不选择 OA。
- 彩色图在线发表不收费。

### 1.3 审稿
- **Double-anonymized**。
- 主稿必须完全匿名。
- Title Page 单独上传，不发给审稿人。

### 1.4 Abstract 与 Keywords
- Abstract：**structured abstract，150–200 words**。
- Keywords：**5–6 个**，尽量具体。

### 1.5 稿件格式
- 首选 Word。
- 不强制模板，但标题层级必须清晰。
- LaTeX 也可接受。
- Title 应简洁、准确、描述性强。

### 1.6 引用格式
- **Chicago Manual of Style**。
- 每一条正文引用必须与参考文献一一对应，作者拼写和年份完全一致。
- 已有同行评议版本时，应更新预印本引用。

### 1.7 Figures / Tables
- 图必须按正文出现顺序连续编号。
- 投稿时图像作为独立文件上传。
- Figure resolution：**300 dpi**。
- 彩图在线免费。
- 使用非自有图表/长引文必须确认版权。

### 1.8 Title Page 必须包含
- Article title
- 全部作者姓名和单位
- Corresponding author 联系方式
- Acknowledgements
- Declaration of conflicting interest
- Funding statement
- Ethical approval / consent statements
- Data availability statement
- 其他可能暴露作者身份的信息

### 1.9 Statements and Declarations
Title Page 需要单独的 **Statements and Declarations**，包括适用子项；不适用也要明确写 Not applicable。

本项目预计包括：
- Ethical considerations: Not applicable（仅使用公开宏观资料）
- Consent to participate: Not applicable
- Consent for publication: Not applicable
- Declaration of conflicting interest
- Funding statement
- Data availability statement
- AI-use disclosure（见下）

### 1.10 Data availability
SAGE 鼓励共享研究数据并给出 Data Availability Statement。

本项目特殊注意：
- 当前 GitHub 仓库含作者账号信息，**直接在匿名审稿稿件中链接公开 GitHub 会破坏匿名性**。
- 双盲阶段应制作匿名 supplementary package，或使用不暴露作者身份的匿名数据存档。
- 接收后再把正式 GitHub/永久链接写回最终稿。

### 1.11 Preprint
- China Report 官方明确：**不接受已经发布在 preprint server 的稿件**。
- 本项目不得在 SSRN / arXiv / ResearchGate preprint 等公开发布完整英文投稿稿。
- GitHub 上的中文研究过程稿是否构成 prior publication 需要谨慎处理；正式英文投稿稿不要公开上传为可识别 preprint 形式。

### 1.12 SAGE AI policy
SAGE 当前政策区分：
- assistive AI（语言、语法、结构建议）：不要求披露；
- generative AI 如果直接影响研究方法、分析、结果、结论，或用于文献整理、代码、可视化、参考文献整理等：**要求披露**。

本项目中 AI 已参与：
- 数据分析代码辅助
- 图表制作
- 文献整理
- 正文组织与表达

因此投稿前按 SAGE 最新政策准备一段简洁透明的 AI-use disclosure；所有数据、数字、引用和结论由作者独立核验。

## 2. 官方没有明确规定、但我们内部需要控制的内容

### 2.1 Research Article 官方网页没有给出明确 word limit
因此不要写成“China Report 要求 8,000 words”。

项目内部工作目标：
- 英文主文控制在约 **7,000–8,500 words**；
- 这个数字是编辑适配目标，不是官方硬性限制；
- 技术细节、完整 robustness、数据审计移至 Supplementary Material。

### 2.2 图表数量
官网没有写硬上限。

项目内部目标：
- 主文只保留真正推动叙事的 6–8 个图/表组合；
- 其余放 Supplementary Material；
- 避免让文章看起来像计量工作论文。

## 3. 对我们稿件的直接含义

China Report 最近 Research Articles 的风格横跨：
- 中国政治与政策变化
- 私营部门政策
- Political economy
- 企业/OFDI 实证研究
- 单一或少数案例的 China studies

因此本文的最佳定位不是：
> “我们估计了薄熙来的 GDP 因果效应。”

而是：
> **Political network shocks have economically different consequences depending on local structural vulnerability. Dalian is the main case; Chongqing is a parallel treated case.**

建议工作标题：
> **Political Network Shocks and Local Economic Vulnerability: Evidence from Dalian after 2012**

Bo Xilai 放入 abstract / introduction / institutional background，不必放标题。
