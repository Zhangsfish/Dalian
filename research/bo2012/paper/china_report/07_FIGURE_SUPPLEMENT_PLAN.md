## 4. Graphics production rules

- English only.
- Figure titles move to manuscript captions; graphic file itself should avoid giant decorative titles.
- Black/grey line styles must remain distinguishable in grayscale.
- No product-style visual design.
- Prefer vector originals and export submission-ready 300 dpi TIFF/PNG where required.
- Keep panel labels A/B/C consistent.
- Every figure caption must state source and whether calculations are authors’ own.
- No visual elements that reveal GitHub username or author identity.
