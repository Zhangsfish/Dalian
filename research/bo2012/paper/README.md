**工作标题：**《政治网络断裂与城市经济失速：2012年薄熙来政治失势后的大连证据》

## 写作原则

1. 把“2012后大连出现相对失速”与“失速由政治网络变化造成”严格分开。
2. 2012作为事件过渡年，不进入主前后期均值。
3. 先给描述性事实，再逐层加入区域嵌套对照、机制证据、平行处理案例与稳健性检验。
4. 不把辽宁当作干净未处理组；不把残差直接命名为政治效应。
5. 图、表、代码均可复现；数据来源回链到 `../data/sources.csv` 和原始研究报告。
